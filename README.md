# ✏️ Pencil — 2D Platformer Game

> **Note:** As this game is scheduled for commercial publication on major storefronts (Steam, GOG, Google Play), the core source code is kept private. This repository serves as a technical and visual showcase of the project.

---

## 📌 Project Overview
**Pencil** is a family-friendly, non-violent 2D platformer (rated PEGI 3) developed entirely from scratch using the **Godot Engine**. As a **solo developer**, I took full ownership of the entire product lifecycle—from software architecture to designing 100% of the custom pixel art without using any pre-made assets. 

Set in engaging school classroom environments with lesson-themed mechanics, the game is architected for a seamless multi-platform release. It is currently in the final stages of development, with a focus on audio integration and finalizing the last few levels before its official launch.

## 🛠️ Engineering & Development Highlights

Building a game entirely solo requires not just creativity, but strict software engineering principles and efficient resource management.

### 1. End-to-End Product Ownership
* **Zero Pre-Made Assets:** Designed and animated every pixel art sprite, tilemap, and UI element independently, showcasing a strong balance between technical execution and creative problem-solving.
* **Commercial Release Pipeline:** Structuring the build process, memory optimization, and deployment pipeline for an upcoming commercial release across PC (Steam, GOG) and Mobile (Google Play) platforms.

### 2. Multi-Platform Architecture
* **Unified Codebase:** Engineered the game logic to run efficiently across mobile (ARM) and PC (x86/x64) architectures without major refactoring.
* **Dynamic Input Handling:** Implemented a scalable input system that seamlessly switches between touch controls (Android/iOS) and keyboard/gamepad inputs (Windows) based on the active build environment.

### 3. Systems & Mechanics Design
* **Physics & Collision:** Programmed custom 2D kinematic physics, ensuring tight, responsive, and lag-free platforming mechanics.
* **State Management:** Utilized state machines to manage player animations, level transitions, and interactive lesson-themed puzzle elements.
* **Optimization:** Managed asset preloading and memory efficiency to ensure smooth 60 FPS performance on lower-end mobile devices.
